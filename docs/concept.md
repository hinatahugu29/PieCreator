# PieCreator V6 Concept Document

## 1. ビジョン
**「Blenderを、あなたの思考スピードで再構築する」**

PieCreator V6は、単なるメニュー作成ツールではありません。アーティストが自分自身のワークフローに合わせて、Blenderのインターフェースを「パーツ単位で設計・構築」するための、最も確実で直感的なUIエンジンです。

## 2. 開発背景
Blender 4.x / 5.x への進化に伴い、APIの厳格化や複雑な操作が増加しています。
これまでの「レコーダー形式」のマクロ作成は、Blenderの内部状態に左右されやすく、不完全なコードが生成されるという課題がありました。

PieCreator V6は、この問題を **「検証済みコマンドのプール（倉庫）」** という新しいパラダイムで解決しました。確実な操作パーツを集め、それらを自在に組み合わせることで、誰もが「絶対に動くマクロ」を作れる環境を提供します。

## 3. V6の3つの柱（Core Pillars）

### ① 確実なマクロ構築「Command Pool」
「右クリックで集めて、並び替えて、合体させる」
不安定な録画に頼らず、右クリックしたその瞬間の確実なAPIパスと数値を「パーツ」として貯蔵。それらをGUI上で並び替えて合体させることで、複雑な連続操作を1つのボタンに凝縮します。

### ② UIタイプの完全同期（Nomenclature Alignment）
Blenderの標準的なUI挙動に準拠。
- **POPUP (Live)**: リアルタイムに数値をいじれる「指先の延長」。
- **DIALOG (OK)**: 確定ボタンで確実に設定を適用する「慎重な操作」。
これらを自由自在に組み合わせ、入れ子構造にすることが可能です。

### ③ 永続性と安定性（Stability & Persistence）
Blender 5.0 の最新仕様に最適化されたクリーンなコードベース。
一度設定したショートカットやデッキ、ライブラリのパーツは、Blenderのアップデートや初期化に左右されず、ユーザーの資産として守り続けられます。

## 4. ターゲット
- **ワークフロー・エンジニア**: 複雑な手順を1クリックに凝縮し、筋肉の負担を減らしたいプロフェッショナル。
- **UIカスタマイザー**: 既存のパイメニューに満足できず、サブメニューやポップアップを縦横無尽に配置したいユーザー。
- **非プログラマー**: Pythonコードを一行も書かずに、複雑なコマンドシーケンスを構築したいアーティスト。

## 5. 未来への約束
PieCreator V6は、カスタマイズの「楽しさ」と「確実さ」を両立させます。
あなたの作ったツールセットは、単なる設定ファイルではなく、あなたの技術を支える「デジタルな道具箱」として進化し続けます。
