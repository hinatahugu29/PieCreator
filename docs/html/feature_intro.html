PieCreator V10.2

最強のワークフローを構築するための、Blender メニュー管理の究極形。

1. メインツールバー Core

🛠️ 基本操作

  • Reload: 設定を強制同期
  • Export/Import: JSONでの一括管理

🌐 デザイナー連携

  • Designer: Webエディタを起動
  • Sync: データの相互同期

2. 高度な自動化ツール Pro

🔍 Scraper

Blender 内の既存メニューを解析。標準機能や他アドオンの具材を瞬時に抜き出し、自分のメニューにアペンドできます。

🔴 Macro Recorder

あなたの操作をリアルタイムに記憶。複雑な手順をボタン一つに凝縮し、作業を自動化します。

3. ナビゲーター & ライブラリ

📂 ツリー形式の階層管理

メニューの親子関係を視覚的に把握。巨大なプロジェクトでも迷子になりません。ライブラリからのドラッグ＆ドロップで効率的に構築可能です。

4. メニューエディタ

📦 デッキ管理

モデリング、スカルプト、ノード編集など、作業コンテキストに応じたメニューセットの切り替え。

🛠️ 表示条件設定

特定のモードやエリアでのみメニューを表示させる、高度なフィルタリング機能。

5. PieDesigner: Sidebar

⚡ リアルタイム同期 (New!)

Paste Items into Menu: Blender でキャプチャした内容を、現在開いているメニューの中身へ直接展開して統合。素材を組み合わせて一つのシステムを作る核となる機能です。

6. Visual Main Canvas

ノードグラフ形式でメニュー遷移を俯瞰し、8方向のスロットを実際の見た目通りにレイアウト。デザインと構造把握を同時に行えます。

7. Properties & API Catalog

🧠 パーソナライズされた API 知識

アドオンがあなたの Blender を「ディープスキャン」。他アドオンを含むすべてのオペレーターをカタログ化し、デザイナー上で強力な補完機能を提供します。
