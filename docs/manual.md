# PieCreator V6 実戦マニュアル

PieCreator V6は、Blender 5.0に最適化された**「ハイブリッド・メニュー・エディター ＆ マクロビルダー」**です。

---

## 1. V6 の新機能

### 1.1 Command Pool (アクション・ライブラリ)
マクロ作成の新しいスタンダードです。
- **パーツ収集**: 任意のボタンや数値を右クリックして「Add to Command Pool」を選択。
- **数値キャプチャ**: スライダー上で右クリックして「Capture Current Value as Part」を選ぶと、その時の数値を固定した「代入命令」として保存。
- **マクロの組み立て**: 「Library」タブでパーツを並び替え、チェックを入れて「ASSEMBLE」を押すだけで、連続操作ボタンが完成。

### 1.2 改良されたUIタイプ
用途に合わせて、直感的に挙動を使い分けられます。
- **[POPUP] (Live)**: マウスを離すと消えますが、開いている間はスライダーなどの変更が**リアルタイム**に反映されます（微調整に最適）。
- **[DIALOG] (OK)**: **OK/Cancelボタン**が表示されます。値をすべて決めてから、最後に確定させたい場合に便利です。
- **[MENU] (List)**: 垂直に並ぶ枠付きリストメニュー。
- **[PIE] (○)**: 素早いアクセスが可能な円形メニュー。

---

## 2. 操作ガイド

### 2.1 メニューの作成
1. **Add Menu**: エディター右上の「+」ボタンから、好みのタイプ（PIE/POPUP等）を選んで作成。
2. **Navigator**: 左側の「Menus」タブで、作成したメニューを選択して編集。

### 2.2 項目（アイテム）の追加
3つの方法でツールを登録できます：
1. **右クリック・直送**: ボタンを右クリックし、「Add to: [メニュー名]」で即座に追加。
2. **バッファ・ペースト**: エディターの「Paste Item」ボタンで、最後にキャプチャした操作を貼り付け。
3. **Library経由（マクロ）**: 貯めたパーツを組み合わせて合体（ASSEMBLE）させる。

### 2.3 メニューの階層化（Nesting）
- エディター上の各アイテムの「LINK」アイコン（鎖のマーク）から、他のメニューをサブメニューとして紐付け可能。
- 階層構造は左側の「Menus」タブにツリー形式で表示されます。

---

## 3. ショートカットとデッキ

- **ショートカットの保存**: メニューの横にあるキー表示枠をクリックして設定。この情報はアドオン設定に永続的に保存されます。
- **デッキ・システム**: 「Deck」を切り替えることで、モデリング用、アニメーション用など、メニューセットを一括で入れ替えることができます。

---

## 4. データのバックアップ

- **Export Settings**: 作成した全てのメニュー、ライブラリのパーツ、ショートカット設定をJSONファイルとして保存します。
- **Import Settings**: 保存したJSONから環境を復元します。

---

## 5. インストール・保存場所

- **場所**: `Edit > Preferences > Add-ons > PieCreator V6`
- **設定ファイル**: `%APPDATA%\Blender Foundation\Blender\5.0\config\pie_creator\menus.json`

---

> [!TIP]
> **「レコーダー (Record)」よりも「ライブラリ (Library)」推奨**
> V6では、右クリックで一つずつ確実なパーツを集めてから組み立てる「Library」方式の方が、Blenderのバージョンに左右されない安定したマクロを作成できます。
