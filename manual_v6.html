PieCreator V6は、Blender 5.0に最適化されたハイブリッド・メニュー・エディターです。複雑な操作を指先一つのコマンドに集約し、クリエイティブを加速させます。

V6 Major Features

Command Pool

不安定な録画からの脱却。検証済みの操作パーツを「倉庫」に集め、自在に組み合わせてマクロ化。失敗しない自動化の完成です。

Capture Value

「現在のこの数値」をそのままマクロの部品に。右クリック一発で数値設定を代入命令としてキャプチャし、確実に再現します。

Hybrid UI Type

POPUPとDIALOGの厳格な分離。リアルタイムに変化を楽しむライブ操作と、OKボタンで慎重に決める確実な操作を使い分け。

Advanced UI Types

POPUP (Live)

マウスを離すと消える軽快なインターフェース。スライダーの数値変更がその場で反映されるため、視覚的な微調整に最適です。

DIALOG (OK)

「OK/キャンセル」を伴う確実なUI。複数の項目をセットしてから一気に適用したい重厚なタスクに向いています。

MENU (Vertical)

整理された垂直リスト。項目数が多く、視認性を重視したいメニューを美しくボックス表示します。

Getting Started

素材を集める

Blenderの任意のボタンや数値の上で右クリック。「Add to Command Pool」でライブラリ（倉庫）にパーツを貯めます。

パーツを並べる

アドオン設定の「Library」タブを開き、パーツを上下ボタンで入れ替えて実行順序を整えます。

マクロを生成

必要なパーツにチェックを入れ、「ASSEMBLE MACRO」をクリック。選択したメニューに即座にマクロボタンが生成されます。

Professional Tip

複雑なコマンドは、まず一つずつ個別に登録して動作を確認し、最後にそれらを倉庫で合体させるのが最も確実な「絶対に動くマクロ」の作り方です。

Data Management

PieCreator V6は、あなたの設定を大切に守ります。

Auto Sync

ショートカット設定やメニュー構造は、アドオンのJSONファイルにリアルタイム同期。Blenderの再起動後も完璧に復元されます。

Easy Export

作成した最強のメニューセットをボタン一つで出力。他のPCやコミュニティと簡単に共有できます。
